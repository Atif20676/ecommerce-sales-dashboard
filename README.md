# 🛒 E-commerce Sales Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Power BI. The dashboard helps visualize sales performance and explore business data through interactive reports.

## 🎯 Objectives
- Analyze e-commerce sales performance.
- Explore revenue and product-level data.
- Identify sales trends and patterns.
- Present data in an interactive dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data transformation and cleaning

## 📊 Dashboard Features
- Interactive sales analysis
- Data visualization for business insights
- Product and sales performance analysis
